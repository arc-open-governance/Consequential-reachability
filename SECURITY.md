# Security

The benchmark works on synthetic or explicitly authorized
environments only. Cases must not carry live credentials, real
personal data, or working exploits against third-party systems.

A security finding — in the schema, the tools, or a case's
subject system — does not belong in a public issue. Report it
privately to **info@recursive-settlement.com**, with the
affected file or case, the exact bytes or steps involved, and
what you observed. Findings are answered on evidence, and a
confirmed finding is credited on the work board under the name
you report with, unless you ask otherwise.
